# Myntra CC SOP Knowledge Base

A static, searchable knowledge base of Myntra Customer Care SOPs for **Delivery**, **Return**, and **Refund** concerns, organized by the topic taxonomy.

## Use locally
Open `index.html` in any browser. No build step required.

Or serve it:
```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy
Deployed on Vercel. To redeploy:
```sh
vercel --prod
```

## Contents
- 36 topics across 3 categories (Delivery / Return / Refund)
- Live search with highlighting
- Sidebar navigation with active-section tracking
- Complete verbatim source notes included
